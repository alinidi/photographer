# **Portfolio project for a photographer.**
**Deploy:** [https://photographer-nu-two.vercel.app/](https://photographer-nu-two.vercel.app/ )
## **Stack:**
- Language - **TypeScript**
- Framework: **React + Next.js**
- Styling: **SCSS**
- Version control: **Git, GitHub**

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
